# FoodZone – Food Ordering Website

A responsive food ordering website developed using HTML5, CSS3, and JavaScript.

## Live Website

https://rakeshgowda17.github.io/Food--Zone/signup.html

## Features

- User Signup and Login
- Food categories
- Search and category filtering
- Product cards
- Add to Cart functionality
- Local Storage for user data
- Responsive design
- Interactive navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Pages

- Signup Page
- Login Page
- Home Page
- Food Menu
- Cart

## Project Objective

The objective of this project is to build a simple and user-friendly food ordering website with an interactive interface and basic user authentication.
